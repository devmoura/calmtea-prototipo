ATUALIZAR GITHUB SEM APAGAR .git
--------------------------------
1. Faça uma cópia do repositório atual funcionando (ou utilize uma branch).
2. Extraia este ZIP em uma pasta temporária.
3. Pelo GitHub Desktop, abra Repository > Show in Explorer.
4. Copie o CONTEÚDO da pasta extraída para a raiz do repositório, substituindo
   src/, public/ e arquivos de configuração, sem excluir a pasta oculta .git.
5. No GitHub Desktop: confira Changes > Commit to main > Push origin.
6. No Vercel, aguarde o novo deploy e confira 'Ready'. Se 'Build failed',
   envie o log de compilação para correção antes de testar no celular.
7. Teste a URL publicada em janela privada e no celular 5G.
8. Refaça o teste OP01 no computador e evento SIM_EVENTO_ACUSTICO com consentimento
   do participante, usando link de sessão remota.
